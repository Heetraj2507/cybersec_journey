# Linux Basics

## 1. Important Linux Directories

* `/` — Root directory; the top level of the Linux filesystem.
* `/home` — Contains users' home directories and personal files.
* `/etc` — Contains system and application configuration files.
* `/var/log` — Contains system, authentication, application, and other log files.
* `/tmp` — Contains temporary files created by users and applications.
* `/bin` — Contains essential Linux commands and executable programs.
* `/usr/bin` — Contains many standard user commands and programs.

## 3. What `/var/log` Contains

`/var/log` contains log files generated by the Linux operating system, applications, and services.

Examples include:

* `auth.log` — Authentication and authorization-related activity.
* `syslog` — General system and service messages.
* `kern.log` — Kernel-related messages.

These logs are useful to SOC analysts for investigating system activity, errors, authentication events, and possible security incidents.

## 4. What `auth.log` Is Used For

`auth.log` is used to record authentication and authorization-related events.

SOC analysts can examine it to identify:

* Username involved in an authentication event.
* Source IP address, when available.
* Successful login attempts.
* Failed login attempts.
* Timestamp of the event.
* `sudo` and other authorization activity.

Example command:

```bash
sudo tail -50 /var/log/auth.log
```

Example information to look for:

```text
Timestamp → When the event happened
Username  → Account involved
Source IP → Origin of a remote connection
Result    → Successful or failed authentication
```

These details can help a SOC analyst detect suspicious login attempts, brute-force activity, and unauthorized access.

# Complete Command Sequence to find `auth.log`

```bash
# 1. Install rsyslog
sudo apt install rsyslog

# 2. Go to the log directory
cd /var/log

# 3. List files and directories
ls -lah

# 4. Check auth.log
ls -lah auth.log

# 5. View the last 50 lines
sudo tail -50 /var/log/auth.log
```
