# Event Viewer
Iimportant part begins.

Open:

```text
Win + R
```

Run:

```text
eventvwr.msc
```

This opens **Event Viewer**.

Event Viewer is extremely important for Windows investigation.

---

# Event Viewer Structure

Navigate to:

```text
Windows Logs
```

You'll find:

```text
Application
Security
System
Setup
Forwarded Events
```

Focus on the first three.

---

# 1. Application Log

Contains events generated by applications.

Examples:

* Application crashes
* Application errors
* Application warnings

---

# 2. System Log

Contains events generated by Windows components.

Examples:

* Service changes
* Driver events
* Boot-related information
* System errors

---

# 3. Security Log

This is particularly important for SOC work.

It can contain events related to:

* Authentication
* Logons
* Account changes
* Privilege use
* Process creation, when auditing is enabled
* Security policy activity

---

# Finding Events

Go to:

```text
Windows Logs
→ Security
```

You'll see columns such as:

```text
keywords
Date and Time
Source
Event ID
Task Category
```

Click an event.

You'll see:

```text
General
Details
```

---

# Event ID

An Event ID is essentially an identifier describing what happened.

For example:

```text
4624
```

means a successful logon under standard Windows auditing.

---

# Exporting Events

**Assignment : Export 10 security events.**

Select the **Security** log.

  You can right-click:
* Security
→ Save All Events As...

### ⚠️ Privacy

Don't upload or share your real computer's Security log .

It can contain usernames, computer names, IP addresses, domain information, and other sensitive information.





# Important Windows Event IDs

| Event ID | Simple Meaning                             |
| -------- | ------------------------------------------ |
| **4624** | Someone successfully logged in             |
| **4625** | Someone tried to log in but failed         |
| **4634** | Someone logged out                         |
| **4648** | Someone used another account's credentials |
| **4672** | A user got special/admin privileges        |
| **4688** | A new program/process started              |
| **4697** | A new Windows service was installed        |
| **4698** | A new scheduled task was created           |
| **4702** | A scheduled task was changed               |
| **4720** | A new user account was created             |
| **4722** | A user account was enabled                 |
| **4725** | A user account was disabled                |
| **4726** | A user account was deleted                 |
| **4732** | A user was added to a security group       |
| **4740** | A user account was locked                  |
| **4768** | A Kerberos login ticket was requested      |
| **4769** | A Kerberos service ticket was requested    |
| **4771** | Kerberos login authentication failed       |
| **5379** | Stored credentials were accessed           |
| **1102** | Security logs were cleared                 |


* Kerberos authentication = the main Windows Security Event IDs.
