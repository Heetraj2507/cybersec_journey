# Questions

## 1. What is a Windows Service?

A Windows service is a program that runs in the background to perform system tasks, such as networking, updates, security, and logging.

## 2. What is the Registry?

The Windows Registry is a database that stores configuration settings for Windows, applications, users, services, and other system components.

## 3. What is Task Scheduler?

Task Scheduler is a Windows tool that automatically runs programs or performs tasks based on triggers such as startup, login, a specific time, or a system event.

## 4. Why Are These Interesting to a SOC Analyst?

They are important because attackers can abuse services, Registry locations, and scheduled tasks for persistence or other malicious activity. A SOC analyst monitors these areas to identify suspicious changes or behavior.
