# Wireshark Labs

A hands-on collection of Wireshark labs for beginners.

## Labs

- Lab 1 – DNS
- Lab 2 – TCP Handshake
- Lab 3 – TLS
- Lab 4 – HTTP vs HTTPS
- Lab 5 – ICMP
- Lab 6 – TCP Streams
- Lab 7 – ARP
- Lab 8 – File Downloads
- Lab 9 – Complete Web Analysis

## Tools

- Wireshark
- Windows/Linux
- Browser
- Ping

## Goal

Learn networking by analyzing real packets.
